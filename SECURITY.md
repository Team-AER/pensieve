# Security policy

## Supported versions

Pensieve is pre-1.0 software. Security fixes are applied to the latest release and the `main` branch.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for the Team-AER/pensieve repository. Include the affected
version or commit, reproduction steps, impact, and any suggested mitigation. Please do not disclose the
issue publicly until a fix is available and maintainers have coordinated disclosure with you.

If private vulnerability reporting is unavailable, contact the maintainers through the Team AER GitHub
organization without including sensitive details in a public issue.

You should receive an acknowledgement within seven days. We will keep you informed while we validate and
remediate the report.
