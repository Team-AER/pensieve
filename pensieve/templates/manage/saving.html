How pages are kept

{{ 'Archive storage on' if storage_on else 'Text only' }} {{ 'Browser rendering on' if browser_on else 'No browser' }}

When you save a link, Pensieve fetches it from this server, renders it in a headless browser so script-built pages come out whole, and keeps the article text (searchable, and what the AI reads), a static copy of the page with its images and styles, a full-page screenshot and the original HTML. None of it needs the site to still be there.

{{ m.icon('share', 16) }} From your phone

Android

Open Pensieve in Chrome and choose Install app (or Add to Home screen). Pensieve then appears in the share sheet of every app: share a page to it and tap Save.

iPhone and iPad

Safari doesn't let web apps join the share sheet, so use a Shortcut. Create a token below, then in the Shortcuts app:

  1. New shortcut, turn on Show in Share Sheet and accept URLs and Safari web pages.
  2. Add Get Contents of URL: {{ base }}/api/v1/save, method POST, request body JSON with a key url set to Shortcut Input.
  3. Add a header Authorization with the value Bearer, a space, and your token.
  4. Optionally add Show Notification "Saved to Pensieve".
