# Reading and save refinements

The phone reader's digest shortcut is a compact destination row. Empty daily/weekly digests have one empty-state heading and a shorter schedule explanation; Generate keeps its existing behavior. Story density, typography, counts and reader-pane behavior are preserved.

The extension capture option stacks its explanation under the label. Its confirmed-save check draws once over 160ms after the server response; initial or live reduced motion shows the static check. Saved fields stay locked, the destination link remains available, and a failure retains the note and enables retry. No new save latency or retention promise is added.

Validation: Ruff; 387 Python tests passed, two optional integration tests skipped; three extension tests passed. Applied reader/empty digest and popup initial/confirmed states rendered at 1440/390/320 with synthetic data. Runtime checks cover keyboard submit, error/retry retaining a note, confirmed locking, and live reduced motion. Current templates, CSS, reader/app scripts and actual extension code were used. Browser APIs and save responses were fixtures; no installed-extension permissions or real server storage was tested.
